# X to Markdown

X（Twitter）の記事・ポストを、ボタンひとつで丸ごと **Markdown** にしてクリップボードにコピーする Tampermonkey ユーザースクリプト。

あとで読む・ノートに残す・AI に食わせる素材を、コピペで消耗せずに一瞬で作るための道具です。

---

## できること

- **X記事（長文 Articles）** の本文をまるごと Markdown で取得（タイトル・本文・表紙画像）
- **通常ポスト**（著者・日時・本文・リンク）
- **画像つきポスト**（画像のURLも一緒に）
- **連投スレッド** を 1 つにまとめて取得（同じ人の続き物）
- **引用リツイート** は引用元の中身まで（引用ブロックで分離）
- **返信ページ** でも「その返信本人」を正しく取得
- 動画はサムネイル画像／すべて Markdown 形式
- 画面右下のボタン、または Tampermonkey メニューから **1 クリック**

> 取れるのは画像の URL（リンク）です。ファイルそのものはダウンロードしません。

---

## 安全性（入れる前にここを読んでOK）

このスクリプトは **「読んで、Markdownにして、クリップボードに入れる」だけ** の道具です。コードは1ファイル・難読化なしなので、入れる前に全部読めます。

| 項目 | このスクリプトの挙動 |
|---|---|
| **外部送信** | **一切しない。** ネットワーク通信のコードがゼロ（`fetch` / `XMLHttpRequest` / `GM_xmlhttpRequest` 等を一切使わない）。あなたのデータがどこかのサーバーに送られることはありません |
| **権限（@grant）** | **2つだけ** — `GM_setClipboard`（クリップボードに書き込む）と `GM_registerMenuCommand`（メニューに項目を足す）。それ以上の権限は要求しません |
| **動く範囲（@match）** | `x.com` と `twitter.com` のみ。**他のサイトでは一切動きません。** `@noframes` で埋め込みフレーム内でも動きません |
| **読むもの** | いま画面に表示されている投稿・記事の中身だけ。**Cookie・パスワード・ログイン情報・他サイトのデータには触りません** |
| **保存** | 端末への保存は一切なし（`localStorage` は自分用のデバッグフラグ `xgrab_debug` を読むだけ） |
| **外部読み込み** | `@require` / `@resource` なし。外部のコードやライブラリを読み込みません |
| **動的コード** | `eval` などの動的コード実行なし |

要するに、**取得したMarkdownはあなたのクリップボードに入るだけで、外には出ていきません。** 心配な人はインストール前に `x-to-markdown.user.js` を上から下まで読んでください（短いです）。

## インストール

1. ブラウザに **Tampermonkey** 拡張を入れる
   - [Chrome / Edge / Arc](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) ／ [Firefox](https://addons.mozilla.org/firefox/addon/tampermonkey/) ／ Safari は App Store の Tampermonkey
2. このリポジトリの **`x-to-markdown.user.js`** を開く
3. Tampermonkey ダッシュボード →「新規スクリプトを作成」→ 中身を貼り付けて保存
   - もしくは `x-to-markdown.user.js` をブラウザにドラッグ → インストール画面で「インストール」
4. `x.com` を開く → 画面右下に **「📋 取得」** ボタンが出れば完了

---

## 使い方

1. 取りたい記事・ポストを **開く**（個別ページで開いてから取得すると狙いがブレません）
2. 右下の **「📋 取得」** を押す（または Tampermonkey アイコン → スクリプトの `>` →「📋 この記事/ポストを取得」）
3. 「取得しました」と出たら、Markdown がクリップボードに入っています。メモやエディタに貼るだけ

X記事の本文を取るときは、表紙やタイトルを **クリックして全文リーダーを開いてから** 押してください（プレビュー表示だと本文がまだ読み込まれていないため）。

## 対応している投稿の種類

| 種類 | 取れるもの |
|---|---|
| 通常ポスト | 著者・日時・本文・リンク・画像 |
| 連投スレッド | 同じ人の続き物をまとめて（`---` 区切り） |
| 引用リツイート | 自分のコメント ＋ 引用元の本文・著者・画像（引用ブロック） |
| 返信 | いま開いている返信本人（親や他人の返信は取らない） |
| X記事（長文） | タイトル・本文ぜんぶ・表紙画像 |

## 注意

- 取得対象は自分が閲覧している公開コンテンツのみ。個人利用の範囲で使ってください。
- X の画面構造（DOM）が変わると取得が崩れることがあります。その時は更新します。
